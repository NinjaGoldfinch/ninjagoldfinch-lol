# FAQ

Short answers to questions a new contributor, operator or integrator is likely to ask, each pointing to the page with the detail.

## Working on the code

**Do I need a Riot API key to work on the site?**
No. `just check` and `just e2e` use fixtures and the mock proxy, and `just dev` can run against the mock too ([workflows/development-setup.md](../workflows/development-setup.md#option-a-against-the-mock-proxy-no-riot-proxy-no-riot-key)). You need one only to see live data from a riot-proxy you run yourself.

**Is there a shared development riot-proxy?**
No. The LAN dev proxy at `192.168.68.46:8080` is dormant, and `PROXY_URL` has no default: "there is no shared dev instance" (`README.md:45`). Run riot-proxy locally with `AUTH_DISABLED=true` ([workflows/development-setup.md](../workflows/development-setup.md#option-b-against-a-riot-proxy-you-run-yourself)).

**Why can't the site just call Riot or Data Dragon from the server?**
All data comes from riot-proxy, which owns the Riot key, the rate limits and the caches; the site may not work around it (`CLAUDE.md:18-22`). The Browser does load images from the Data Dragon CDN and CommunityDragon directly, and the server reads one CommunityDragon file for stat shard names ([architecture/overview.md](../architecture/overview.md)).

**riot-proxy lacks a field I need. What now?**
Stop and ask; riot-proxy changes first, then the spec is refreshed from its release ([workflows/adding-a-proxy-call.md](../workflows/adding-a-proxy-call.md)).

**Can I edit `src/lib/api/schema.d.ts`?**
No. It is generated by `just gen` from `openapi/riot-proxy.json`, and `just check` fails if it drifts (`justfile:15-22`).

**Where is CI?**
`.github/workflows/ci.yml` runs the gate, `scripts/check.sh` (what `just check` runs), on every pull request and on `main` (ADR-050; [workflows/ci.md](../workflows/ci.md)). The pre-push hook still runs `just check` locally.

**Why does the pre-commit hook reject my commit?**
Either you are on `main`, or a staged line contains `rpx_` or `RGAPI-` followed by a key character (`.githooks/pre-commit:4-23`). Work on a task branch; redact keys.

**Can I push from a git worktree?**
Yes. Nothing in the gate runs git since the preview VM's deploy test went (ADR-067); before that, RV-01 and FIX-06 kept its scratch repositories clear of the location variables git exports to hooks.

**Why must every page work without JavaScript?**
It is a project rule (`CLAUDE.md:59`): pages are rendered on the server and enhanced on top, and the e2e tests check each page with JavaScript off ([workflows/testing.md](../workflows/testing.md#browser-tests)).

**Why are custom games missing from profiles?**
Riot policy: no custom-queue match history (`CLAUDE.md:24`); queue 0 or none counts as custom (`src/lib/domain/matches.ts:156-158`).

**Can the site show MMR or ELO estimates?**
No; Riot policy (`CLAUDE.md:24`).

## Running it

**Where does production run and how do I deploy?**
On `ngf-prod-syd1`, as `node build` under systemd, behind a Cloudflare Tunnel. Deploy is five commands on the host ([deployment/overview.md](../deployment/overview.md), [workflows/release-process.md](../workflows/release-process.md#4-deploy-to-production)).

**Why is `ORIGIN` on the build command and not in the env file?**
adapter-node 6 does not read it at runtime; it is baked into the build, and form posts are accepted only from it (`vite.config.ts:16-19`, ADR-014).

**Does the site have a database or a bucket to back up?**
No. Its only host state is the settings file and the unit file ([deployment/backup-and-restore.md](../deployment/backup-and-restore.md)).

**Why do pages say "Temporarily unavailable"?**
riot-proxy is down (503 at once), hung (503 after 5 or 30 s), rejecting the key (503), or riot-proxy cannot reach Riot (503) ([operations/troubleshooting.md](../operations/troubleshooting.md)).

**Why "Too many requests"?**
Either the site's riot-proxy quota or the Riot key's budget is used up; the page says how long to wait ([api/errors.md](../api/errors.md)).

**How long until a change in a player's games shows?**
A profile page is cached at the edge for 60 s and may be served stale for up to 5 minutes while it refreshes (`src/lib/server/cache.ts:6-7`); riot-proxy caches Riot data with its own TTLs ([data/caching.md](../data/caching.md)). The Refresh button asks riot-proxy to re-read from Riot.

**Is the production key's name `ninjagoldfinch-web` or `ninjagoldfinch-lol-prod`?**
Production uses `ninjagoldfinch-lol-prod` (owner, 2026-10-19). The original plan suggests `ninjagoldfinch-web` (`docs/IMPLEMENTATION.md:189`), now marked superseded there.

**Can I use the site as an API?**
No. It serves HTML pages, redirects and `/healthz` only; consumers wanting data should get their own riot-proxy key ([api/endpoints.md](../api/endpoints.md)).
